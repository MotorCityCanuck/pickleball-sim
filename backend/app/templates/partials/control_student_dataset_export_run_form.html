Release Architecture
1. Initial snapshot
Creates the starting warehouse state students load once.
2. Monthly incremental packages
Each later release is keyed to one release month and is designed for append + merge workflows.
3. Optional tainting layer
When enabled, clean and tainted copies are emitted in parallel for instructor comparison workflows.
