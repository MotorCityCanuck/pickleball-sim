## Partitioning Strategy

- Release-family partitioning is directory-based, not Hive-style partitioning.
- The exporter writes one baseline folder named
  `<release_name>_initial_history`.
- It can also write monthly incremental folders named
  `<release_name>_snapshot_YYYY_MM`.
- Inside each concrete release folder, each dataset is a single unpartitioned
  `.parquet` file.
- `manifest.json` carries release scope metadata such as snapshot month, fact
  batches, and file checksums.
- `instructor_only/data_quality_injection_manifest.parquet` is optional and is
  only present when the release family includes the instructor-only companion
  folder.

## Referential Relationship Summary

The active export contract preserves these foreign key relationships:

- `clubs.region_id -> regions.id`
- `club_memberships.player_id -> player_master.player_id`
- `club_memberships.club_id -> clubs.id`
- `matches.region_id -> regions.id`
- `matches.batch_id -> monthly_batches.id`
- `matches.winning_team_id -> match_teams.id`
- `match_games.match_id -> matches.id`
- `match_teams.match_id -> matches.id`
- `match_team_players.match_team_id -> match_teams.id`
- `match_team_players.player_id -> player_master.player_id`
- `player_assessment_history.player_id -> player_master.player_id`
- `player_assessment_history.batch_id -> monthly_batches.id`
- `player_registrations.player_id -> player_master.player_id`
- `player_registrations.batch_id -> monthly_batches.id`
- `player_registrations.assigned_region_id -> regions.id`
- `player_master.home_region_id -> regions.id`
- `team_memberships.team_id -> teams.id`
- `team_memberships.player_id -> player_master.player_id`

## Notable Observations

- The documented semantic contract describes several date columns as `DATE`, but
  the analyzed checked-in Parquet files currently store those columns as
  `string`.
- Several columns are physically typed as `null` in this release artifact
  because every value is null in the sampled export, including:
  `club_memberships.end_date`, `team_memberships.left_date`,
  `monthly_batches.assessment_update_count`, and all columns in the empty
  `player_assessment_history.parquet`.
